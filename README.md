# ResumeOnline

A bilingual technical resume website for Shaojie Tan, styled after the open-source [resume-ng](https://github.com/fky2015/resume-ng) LaTeX template.

## Features

- Chinese and English pages generated by Hugo
- Responsive desktop and mobile layouts
- Print-friendly A4 layout
- Chinese and English PDFs compiled from `resume-ng` with XeLaTeX
- Automatic GitHub Pages deployment on every push to `main`

## Local preview

```powershell
hugo server
```

Open the URL printed by Hugo. The production site is deployed by `.github/workflows/deploy.yml`.

## Update content

- Website content: `data/resume.yaml`
- Chinese PDF: `latex/resume-zh.tex`
- English PDF: `latex/resume-en.tex`
- Website styles: `assets/css/main.css`

## Privacy

The public version intentionally omits age, gender, ethnicity, birthplace, and phone number.
